# Savepoint Architecture

React owns all persistent financial state, API calls, forms, and saves. Phaser owns rendering, movement, collision, camera, and interaction zones only. Never duplicate financial or XP logic in Phaser. World actions must call the existing React actions. Keep the dashboard accessible through the home computer.

# Usage Efficiency

Search before reading; read targeted ranges. Avoid broad repository inspection, unrelated refactors, optional improvements, and repeated expensive validation. Reuse existing code. Stop at the requested milestone.
